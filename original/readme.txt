☆インストール方法☆
  BGW.LZHを適当なフォルダに解凍して下さい。
  BGW.EXEを起動すればゲームが開始されます。	
  フル画面で起動する場合は、他のアプリを終わらせてからのほうが良いです。
  大丈夫だとは思いますがWINDOWSを独占してしまいますので一応。
  アンインストールはフォルダごと削除して下さい。


☆遊び方☆
  「いんすまうす」を操ってどんどん上に登ってください。
  謎のアイテム「ぶんぐるＷＡ」を取ると点数が入ります。
  連続で取る事で加算される点数が上がります。
  頂上にある「金のぶんぐるＷＡ」を取るとクリアです。


☆操作方法☆
  カーソル左右   ：「いんすまうす」が左右に動きます。
  スペース  キー ：「いんすまうす」がジャンプします。
                    ※１ ジャンプするたびにPOWERが減ります。
                         POWERが無くなるまでジャンプ出来ます。
　                       最大で３段までジャンプ出来ます。
                    ※２ 床の中心でＪＵＭＰすると高く飛べます。
  ＥＳＣ    キー ： WINDOWSに戻ります。
  CTRL ＋ Ｒキー ： タイトル画面に戻ります。


☆キャラ説明☆
  いんすまうす      ：主人公です。
  壁(青・緑・赤)    ：乗る事でPOWERを回復する事が出来ますが
                      徐々に崩れていきます。
                      赤・緑・青の順に崩れるのが早いです。
  壁(茶色)          ：乗る事でPOWERを回復する事が出来ます。崩れる事は有りません。
  ぶんぐるＷＡ（紫）：連続して取る事で100,500,1000点と加算していきます。若干POWERが回復します。
  ぶんぐるＷＡ（金）：これを取るとクリアになります。


☆その他☆
  ・オブション画面説明
      GAME LEVEL         ... ゲームの難易度です。
      JUMP BUTTON ASSIGN ... ＪＵＭＰのボタンの変更を行います。
                             設定したいボタンを押すことで変更出来ます。
      WAIT               ... 60FPSが再現されない場合のみONにして下さい。
      SOFTWARE VSYNC     ... 60FPSを再現します。
      RANKING            ... ランキングを表示します。

  ・Game.iniファイル説明
      fullscreen=ONにするとフル画面になり、OFFにするとWindows画面になります。
      ※その他の値は変更しないで下さい。
