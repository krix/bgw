* Installation *
  Extract BGW.LZH into a suitable folder.
  Run BGW.EXE and the game will start.
  If you start it in fullscreen, it is better to close other applications first.
  I think it will be fine, but just in case, since it takes over Windows exclusively.
  To uninstall, delete the entire folder.


* How to play *
  Control "Insumausu" and keep climbing upward.
  Collect the mysterious item "Bunguru WA" to earn points.
  Collecting them consecutively increases the points awarded.
  Collect the "Golden Bunguru WA" at the top to clear the game.


* Controls *
  Left/Right cursor : "Insumausu" moves left and right.
  Space key         : "Insumausu" jumps.
                      *1 Each jump decreases POWER.
                           You can jump until POWER runs out.
                           You can jump up to 3 times in succession.
                      *2 Jumping at the center of the floor lets you jump higher.
  ESC key           : Return to Windows.
  CTRL + R keys     : Return to the title screen.


* Character descriptions *
  Insumausu           : The protagonist.
  Walls (blue/green/red): Standing on them restores POWER, but they
                          gradually crumble.
                          Red, green, and blue crumble fastest, in that order.
  Walls (brown)       : Standing on them restores POWER. They never crumble.
  Bunguru WA (purple) : Collecting them consecutively awards 100, 500, and
                        1000 points incrementally. Restores a little POWER.
  Bunguru WA (gold)   : Collecting this clears the game.


* Other *
  - Option screen description
      GAME LEVEL         ... The game's difficulty.
      JUMP BUTTON ASSIGN ... Changes the JUMP button.
                             You can change it by pressing the button you
                             want to assign.
      WAIT               ... Turn this ON only if 60FPS is not reproduced.
      SOFTWARE VSYNC     ... Reproduces 60FPS.
      RANKING            ... Displays the ranking.

  - Game.ini file description
      fullscreen=ON makes it fullscreen, and OFF makes it a Windows screen.
      * Do not change any other values.
